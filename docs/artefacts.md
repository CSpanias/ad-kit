# Artefacts

Artefacts are generated during enumeration and assessment checks, written to the `ad-kit/` directory.

## Enumeration Artefacts

Generated by `ad-kit enum`:

| File | Description |
|------|-------------|
| `session.json` | Session metadata (domain, DC IPs, credentials validated, etc.) |
| `domain.txt` | Target domain name |
| `dc-hostnames.txt` | Discovered Domain Controller hostnames |
| `dc-ips.txt` | Discovered Domain Controller IP addresses |
| `domain-users-filtered.txt` | Filtered domain user list |
| `domain-computers.txt` | Domain computer hostnames |
| `*.zip` | BloodHound collection (if collection enabled) |
| `*.ntds` | NTDS dump (if dump enabled) |

## Check Artefacts

Generated by `ad-kit check`:

| File | Description |
|------|-------------|
| `ad-kit_findings.html` | Self-contained HTML report with copyable findings |
| `ad-kit_findings.json` | Machine-readable findings export for external reporting platforms |
| `ad-kit_findings.xml` | SureFormat findings export when using `--csacyber` instead of JSON |
| `ad-kit_findings-dc.xml` | DC-only SureFormat findings when also using `--dc` |
| `evidence/*.txt` | Raw command output evidence |

## Retrieval

`ad-kit enum` can generate an SCP command to retrieve artefacts from your jumpbox:

```bash
scp "user@host:/remote/dir/*.zip" "user@host:/remote/dir/*.ntds*" ./
```

BloodHound collections (`.zip`) and NTDS dumps (`.ntds`) can be processed using [password-audit](https://github.com/CSpanias/password-audit).
